# AggreProt Predictor

- Web page: https://loschmidt.chemi.muni.cz/aggreprot/
- Paper: https://academic.oup.com/nar/article/52/W1/W159/7683054

## Run predictor

Use Python 3.8.

Install the predictor:

```bash
pip install https://github.com/loschmidt/aggreprot-predictor/archive/refs/heads/main.zip
```

Run the predictor:

```bash
aggreprot-predictor predict-sequential-batch --out-dir out sequences.fa
```
